- Мозг ассистента: DeepSeek, две ступени — `deepseek-flash` (лёгкие вопросы, бот в группах) и `deepseek-v4-pro` (вопросы «почему/сравни», добор ответа). Протокол OpenAI-совместимый chat/completions + 28 инструментов.
- Объём за 10.09–10.10: 139 запросов, 401 обращение к модели (≈2.9 раунда инструментов на вопрос). Это очень мало — цена месяца у любой модели копеечная, решает качество и скорость.

- Пиковый тариф DeepSeek (×2) действует 01–04 и 06–10 UTC по будням = 06–09 и 11–15 по Ташкенту; в эти часы приходится ~60% наших запросов.

## Что мешает переключиться и что сделано

- OpenAI GPT-6 с включённым рассуждением не принимает function tools в chat/completions (400 «use /v1/responses»), а `gpt-6.1-sol` не умеет `reasoning_effort: none`. Поэтому в `services/ai_assistant.py` добавлен пресет `openai` с протоколом Responses API: тот же цикл инструментов, переводчик messages↔input items, рассуждение между вызовами инструментов сохраняется (store=false, encrypted reasoning). Глубина — `AI_EFFORT` (low по умолчанию, так и тестировалось).
- Добавлен пресет `gemini` (их OpenAI-совместимый адрес, ключ ASR) — на случай платного плана.
- Консоль /dev показывает провайдера и протокол. Тесты: `test_ai_provider.py` разделы 8–11.
- По умолчанию всё как было: без `AI_PROVIDER` на Railway бот остаётся на DeepSeek.

## Рекомендация

Перейти на `gpt-6.1-sol` обеими ступенями: вместе с Opus 5.5 единственная модель с 5/5, при этом в 2 раза быстрее DeepSeek и в 7 раз дешевле Opus; цена месяца ≈ $3.5 против ≈ $2–5 сейчас. Ключ OpenAI уже стоит на Railway. Вариант «максимум качества»: `AI_PROVIDER=anthropic` с `AI_MODEL=claude-sonnet-5-5` и `AI_SMART_MODEL=claude-opus-5-5` — быстрые ответы на простое, Opus на «почему/сравни», ≈ $12–15/мес.

Переключение (одна переменная, деплой не нужен — Railway перезапустит сервис):

```bash
railway variables --set AI_PROVIDER=openai
```

Откат: убрать переменную `AI_PROVIDER` — бот вернётся на DeepSeek. Дёшево-быструю ступень можно включить позже: `AI_MODEL=gpt-6-luna` при `AI_SMART_MODEL=gpt-6.1-sol` (роутер отправит «почему/сравни» на Sol), но по тесту luna путает похожих клиентов.

Переключение на Claude: `railway variables --set AI_PROVIDER=anthropic` (ключ уже на Railway; по умолчанию Sonnet 5.5 обеими ступенями, модели ступеней задаются `AI_MODEL` / `AI_SMART_MODEL`, глубина рассуждения `AI_EFFORT`).
