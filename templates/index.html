Чтобы добавить новые файлы — используй кнопку «📦 Packing lists» в карточке партии.
Массовая загрузка Packing lists
Каждый файл будет автоматически прикреплён к BL по совпадению BL кода в имени файла (поиск только в этой партии, с учётом merged_codes). Поддерживается PDF, DOC, DOCX, XLS, XLSX, XLSM, PNG, JPG, ZIP.

Редактировать BL
Можно выбрать найденную группу выше или указать chat_id вручную.
📎 Файлы прикрепляются массово через кнопку «📦 Packing lists» в карточке партии — по совпадению имени файла с BL кодом.
Перенести BL код
BL будет перенесён в другую партию вместе с привязкой клиента и связанными инцидентами.
Объединить BL коды
Данные, файлы и инциденты будут перенесены в основной BL. Второй код станет алиасом и в Telegram будет приходить одним блоком.
